# 초기 언어와 라이브러리 동작 수정 계획

기준은 2026년 9월 25일 확인한 origin/main의 d179109 커밋이다. 기존 작업 트리의 변경은 보존한다. 현재 저장소에는 열린 GitHub 이슈가 없어 직전 검토에서 확인한 다섯 문제를 대상으로 삼는다.

## 작업 순서

1. 쿠키가 없는 첫 방문에서 서버 HTML과 브라우저의 첫 렌더링을 영어로 맞춘다. 사용자가 저장한 한국어 선택은 유지한다. 홈과 공통 번역을 처음부터 제공한다.
2. 일반 훅과 createI18n이 요청한 네임스페이스만 읽도록 통일한다. 네임스페이스는 화면별 번역을 구분하는 이름이다. 같은 키를 여러 화면에서 안전하게 사용하기 위해 필요하다.
3. 서버 캐시에 번역 폴더와 fallback 설정을 포함한다. 같은 프로세스에서 다른 번역 폴더를 사용할 때 데이터가 섞이지 않도록 한다.
4. 번역 로딩 실패를 오류로 보관한다. 반복 요청은 방지하고 사용자가 retry 함수를 호출하면 다시 시도한다. 일부 언어가 성공했으면 기존 fallback 동작을 유지한다.
5. JSON 설정을 CLI와 서버가 읽는 기준으로 삼는다. TypeScript 초기화 옵션은 JSON과 이를 가져오는 타입 보조 파일을 함께 생성한다. 공개 설정 타입이 CLI 옵션을 표현하도록 보완한다.
6. 실행에 필요한 CLI 의존성을 일반 의존성으로 선언한다. 선언한 Node 18 환경과 CommonJS 출력에 맞는 Inquirer 버전을 사용한다.

## 검증 기준

첫 HTML에서 영어 문구가 출력되어야 한다. 한국어 쿠키가 있으면 한국어가 출력되어야 한다. 브라우저의 첫 렌더링에서 언어 불일치가 없어야 한다.

같은 키를 가진 서로 다른 네임스페이스와 번역 폴더가 독립적으로 동작해야 한다. 모든 번역 로딩이 실패하면 준비 완료가 아니어야 한다. 명시적인 재시도가 성공하면 번역과 준비 상태가 회복되어야 한다.

core와 tools와 demo의 테스트와 빌드를 확인한다. 배포용 CLI 패키지를 별도 환경에 설치해 실행한다. 로컬 검증과 CI와 운영 반영은 구분해서 보고한다.

## 확인 결과

core 테스트 169개와 tools 테스트 348개와 demo 테스트 44개가 통과했다. tools에서 기존에 제외하던 테스트 21개는 그대로 제외된다. 사이트 프로덕션 빌드가 완료되었다.

쿠키가 없는 요청과 영어 쿠키와 잘못된 쿠키는 첫 HTML부터 영어를 반환했다. 한국어 쿠키는 한국어를 반환했다. 브라우저에서 언어 전환과 새로고침 후 선택 유지가 확인되었고 콘솔 오류는 없었다.

Node 18과 Node 26에서 배포용 CLI 패키지만 설치한 뒤 명령 11개의 도움말과 TypeScript 초기화가 통과했다. 이 검증을 CI에도 추가했다.

core 패키지의 설치 후 실행과 타입 검증은 통과했지만 npm audit 단계에서 GHSA-38hw-f37p-99jj 권고로 전체 패키지 검증이 중단되었다. 그 뒤의 독립적인 RSC 빌드 검증은 실행되지 않았다. 이 결과는 소스 변경의 회귀 테스트와 구분한다.

운영 사이트 배포와 npm 출시는 이 작업의 로컬 검증 결과에 포함하지 않는다.
